# Demo walkthrough

1. Run `npm run demo` and open the dashboard.
2. Switch EN / 中文; the business records and current inputs stay intact.
3. Focus the fund/project/task iceberg regions and return to Overview.
4. Open Funds, Projects and Tasks to inspect the linked fictional records.
5. Open Documents and preview a `Demo-*.md` file; these were created through the normal upload API.
6. Inspect priorities and the weekly draft. These are demonstration records, not real investor decisions.

The demo is local and resets its in-memory records when the API restarts. Do not use it for real records. AI configuration is optional and no provider credentials are included.
